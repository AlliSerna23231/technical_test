⚙️ Instalación
Sigue estos pasos para levantar el entorno de desarrollo:


1. Clona el repositorio
git clone <URL_DEL_REPOSITORIO>
cd training-tracker-api

2. Instala las dependencias
npm install

3. Configura la base de datos
- Edita el archivo data-source.ts con tus credenciales de PostgreSQL.
- Crea la base de datos si aún no existe.


4. Ejecuta las migraciones 

5. Inicia el servidor en modo desarrollo
npm run start:dev

API desarrollada con NestJS para gestionar rutinas de entrenamiento, usuarios y autenticación. Ideal para aplicaciones fitness que requieren una arquitectura robusta y escalable.

🚀 Características
• 	Gestión de usuarios y autenticación
• 	CRUD de rutinas de entrenamiento
• 	Integración con PostgreSQL
• 	Arquitectura modular con NestJS
